# Third-party notices

MnemoWeave is based on [dsh-mnemon](https://github.com/omdsh-dev/dsh-mnemon) 0.5.46. The original MIT copyright and license are preserved in [LICENSE](LICENSE).

`dsh-mnemon` is licensed under the MIT License. Its provider adapters are original TypeScript integrations adapted to DSH's contracts. This package no longer ships third-party provider adapters: only the Mnemon Native adapter remains, and it drives the upstream Mnemon CLI rather than bundling a provider SDK or service.

The standalone sync server embeds the license texts for [@swan-io/srp](https://github.com/swan-io/srp), its [jsbn](https://github.com/andyperlitch/jsbn) dependency, and [Zod](https://github.com/colinhacks/zod) in the generated server file.
