## P0-1：主开发语言

**最终选择：TypeScript**

Mneme 以 TypeScript 作为主要开发语言。

要求：
- 核心业务逻辑使用 TypeScript。
- Server、Bridge、协议层、Adapter SDK 和客户端插件尽可能共享类型定义。
- 使用严格类型检查。
- 统一管理依赖和构建流程。
- 允许调用 Go 等语言编写的外部程序，但不改变主开发语言决策。
