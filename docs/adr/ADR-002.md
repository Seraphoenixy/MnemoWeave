## P0-2：核心部署形态

**最终选择：模块化单体（Modular Monolith）**

Mneme Server 采用单体部署，但内部通过明确的业务模块和接口进行组织。

各模块可以独立开发、测试，具有明确的职责和依赖边界。

不采用：
- 第一阶段即拆分微服务。
- 所有功能混合在一个无边界的代码模块中。

这样既降低部署和运维复杂度，又保留未来拆分的可能性。
