## P0-3：记忆来源架构

**最终选择：完整继承 Source / Strategy / Enhancement / View**

参考 dsh-mnemon 的核心抽象。

- Source：定义记忆来源以及能够提供的能力。
- Strategy：决定本轮执行采用哪些 Source，以及如何组合。
- Enhancement：通过标准扩展点增强策略和处理能力。
- View：经过组合、校验后形成不可变的运行时记忆视图。

Mneme 不应将这些抽象简单合并为一个 Memory Provider。

需要保留来源、策略、增强和最终视图之间的职责区别。
