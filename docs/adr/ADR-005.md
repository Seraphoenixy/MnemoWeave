# ADR-005：Session 事件保存

状态：已接受（用户交接基线）。

决策：选择性保存消息和重要工具事件。

共同约束：不能无限期保存所有会话原文；事件保存与记忆沉淀区分；后台整理不能绕过候选审核；保持模块边界。

## P0-5：Session 事件保存

**最终选择：选择性保存消息和重要工具事件**

不无限期保存完整会话历史。

根据事件的重要程度选择性保存：
- 有长期知识价值的消息。
- 重要工具调用及其结果。
- 关键技术决策。
- 重要错误及解决过程。
- 影响后续任务的工程信息。

普通对话和无价值的工具事件不应永久保存。
