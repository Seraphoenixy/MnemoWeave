# ADR-007

状态：已接受（交接说明转录；非历史原始 ADR 的重建）。

### ADR-007：R1 HTTP + MCP 双接口

选择方案 C。

HTTP 和 MCP 双接口：

- HTTP：生命周期事件、Session 上传、View、任务管理等。
- MCP：Recall、Remember、Link、Forget 等记忆业务工具。
- 两者共享业务逻辑，不允许分别实现两套记忆业务。

# 二、R1：对外通信接口

## R1-1：HTTP / MCP 接口架构

**最终选择：方案 C——HTTP + MCP 双接口**

Mneme 同时提供 HTTP 和 MCP 两种接口。

HTTP 面向常规程序化调用、客户端通信、任务管理及同步等场景。

MCP 面向 AI Host，提供语义化记忆工具，使工作模型可以直接使用记忆能力。

两种接口共享统一的业务核心，不能分别实现两套记忆业务逻辑。
