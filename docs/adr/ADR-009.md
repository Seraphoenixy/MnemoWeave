# 四、R3：Strategy 与 Core 的职责边界

## R3-1：Strategy 执行架构

**最终选择：方案 B**

Strategy 负责声明本轮需要执行的组合计划，Core 负责验证和执行协调。

具体职责：

- Strategy 根据当前上下文确定参与的 Source、Enhancement 和相关处理规则。
- Strategy 生成 Composition Plan。
- Core 检查 Plan 的合法性、能力声明和授权条件。
- Core 负责调用 Pipeline 执行计划。
- 最终由 View Composer 生成不可变 View。

不允许 Strategy 任意越过 Core 直接操作底层 Provider。
