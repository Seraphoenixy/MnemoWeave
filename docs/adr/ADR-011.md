# 六、R5：规划机制

## R5-1：规划机制

**最终选择：方案 D**

采用规则规划与 LLM Planner 相结合的机制。

优先使用确定性规则完成常规规划。

只有当规则无法充分确定执行方案时，才按需调用 LLM Planner。

避免所有普通 Recall、Remember 都产生额外推理调用。

LLM Planner 负责处理规则难以确定的复杂组合和语义判断，最终执行仍受 Core、Pipeline、Capability 和 Grants 约束。
