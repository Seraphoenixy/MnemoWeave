# 七、R6：Enhancement 架构

## R6-1：Enhancement 架构

**最终选择：方案 B**

Enhancement 采用标准化扩展架构，通过明确的插槽和能力声明参与执行流程。

不允许任意扩展直接修改核心业务状态。

Enhancement 必须遵循 Core 的执行和权限约束。

## R6-2：模型调用权限

**最终选择：declared**

模型调用权限必须由组件明确声明。

只有具备相应声明和授权的组件才能通过 Model Gateway 调用模型。

不能让所有 Source、Strategy 和 Enhancement 默认拥有模型调用权限。
