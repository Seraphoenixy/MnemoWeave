# 十一、R10：Model Gateway

## R10-1：Model Gateway 架构

**最终选择：方案 B——Task-oriented Model Gateway**

通过统一 Model Gateway 管理模型调用。

调用方不直接绑定具体模型服务商，而是根据任务类型申请模型能力。

Model Gateway 负责：

- 模型配置。
- 模型选择。
- 调用参数。
- 超时。
- 错误处理。
- 调用结果。
- 使用记录。

## R10-2：工作模型与后台模型关系

**最终选择：方案 2——工作模型优先，后台模型按需补充**

工作模型是记忆沉淀的主要决策来源。

工作模型可以主动 Remember，也可以根据工作内容提交记忆更新。

后台模型用于按需完成辅助处理，例如：
- 候选记忆质量检查。
- 知识抽象。
- 冲突识别。
- 自动整理。
- 语义分析。

后台模型不是独立的记忆大脑，不允许记忆系统脱离上游编排层自行寻找模型。
