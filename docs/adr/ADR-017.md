# 十二、R11：模型路由和失败处理

## R11-1：Model Routing

**最终选择：方案 C**

采用统一的模型路由机制。

模型选择由 Model Gateway / Routing 层统一管理，而不是散布在各个业务模块。

不同任务可以配置不同的模型要求，路由根据任务类型、能力、配置和可用性选择模型。

## R11-2：模型失败与降级

**最终选择：方案 C**

采用统一的模型失败处理与降级机制。

模型调用失败不应导致整个记忆系统不可用。

需要区分：

- 可以重试的临时错误。
- 模型服务不可用。
- 超时。
- 参数或权限错误。
- 模型能力不满足要求。

可根据任务重要程度采取重试、切换模型、延迟处理或转人工介入。
