# 十三、R12：任务队列和 Worker

## R12-1：Task Queue

**最终选择：方案 B**

采用持久化任务队列。

任务不只存在于内存中，而是具有持久化状态，可以在进程重启后恢复。

## R12-2：Worker 部署

**最终选择：方案 B**

采用既定的 Worker 部署方案。

Worker 负责执行后台任务和 Pipeline。

与 R20-11 一致，第一阶段不将 Worker 拆分成独立微服务，而是运行在 Server 模块化单体进程内部。

## R12-3：重试与恢复

**最终选择：方案 C**

采用既定的重试与恢复方案。

任务需要支持失败重试、状态恢复和异常处理。

后续 R13 和 R20-5 进一步确定：

- Task / Pipeline Run / Receipt 独立关联。
- 稳定幂等键。
- 检查点恢复。
- 显式暂停和取消。
- 人工介入。
