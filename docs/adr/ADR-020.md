# 十五、R14：数据库和存储

## R14-1：Mneme 自身数据库选型

**最终选择：方案 A——SQLite 优先**

Mneme 自身采用 SQLite。

优先考虑自部署、低运维成本和单实例部署。

## R14-2：业务数据组织

**最终选择：方案 B——单数据库，按模块独立建表**

各业务模块共享同一个 SQLite 数据库。

不同模块独立拥有自己的数据表和数据访问边界。

不为每个业务模块建立独立数据库。

## R14-3：原始事件与大型内容

**最终选择：方案 B——数据库元数据 + 本地内容寻址文件存储**

SQLite 保存元数据、索引和文件引用。

大型原始内容放在本地内容寻址存储中。

通过内容 Hash 和引用关系管理文件，避免将大型内容全部直接存入数据库。

## R14-4：同步与备份

**最终选择：方案 C——完全依赖自部署服务器，不提供通用文件同步和备份机制**

不建设通用云盘、文件同步和用户云备份服务。

后续 R16、R17、R20 增加的记忆副本同步、增量变更和升级安全备份属于 Mneme 自身业务机制，不属于通用文件同步服务。
