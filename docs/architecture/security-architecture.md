# 安全边界

已接受：Bridge 身份 + Host 身份 + 作用域授权，支持独立撤销、轮换、TLS、审计。能力协商不授予访问权限。Grants 在实际操作边界强制执行，不能依赖模型遵循提示词。

当前切片绑定 127.0.0.1，使用显式 Bearer Token；stdio MCP 继承启动者权限。模型可以提交候选、Recall 和查回执；审核及 Outbox 驱动正式写入，不开放直接写入工具。

异常人工审核/重试需要独立 operator token，只在 HTTP 边界验证；普通 token 无权调用，MCP 不暴露这些工具。操作人由可信边界指定为 local-operator，不从模型输入读取。令牌不能相同；不要把 operator token 传给 Host。模型结果按严格 Schema 校验，拒绝/中断/解析失败一律转人工；模型输入视为不可信数据。

此开发保护不替代最终 Bridge/Host 注册与作用域系统。离线 Lease、撤销时限、本地存储保护、密钥托管和日志脱敏仍待设计。不得远端开放当前开发服务。
