# DSH 界面

DSH 插件包含 `mnemo-weave` 和 `mnemo-weave-ui` 两个条目，分别负责会话注入与界面。浏览器页面通过 DSH RPC 调用 Host 半，后者用共享客户端访问本机 Server。凭据由 Host 读取。

## 页面

记忆中枢有六个页签，设置中可选择默认打开页。

| 页签 | 操作 |
|---|---|
| 概览 | 查看连接、范围、条目数和最近一次注入 |
| 运行时记忆 | 查看、新增、编辑及启停准则。适用准则超出预算时拒绝启用 |
| 项目档案 | 搜索标题、项目或正文；查看证据与验证状态；新增和按版本编辑 |
| 正式记忆 | 概览显示关系图谱；检索按相似度查找；内容支持筛选、分页、详情、历史、新增、编辑与撤回；实体提供索引 |
| 技能 | 从已加载会话复盘，生成带证据的草案与用例，自动回测；也可填写基线、草案和检查项手动回测 |
| 设置 | 界面偏好、本机连接与远端同步、自动启动、注入和诊断 |

正式记忆编辑和撤回使用表单打开时的版本。遇到冲突时可对照打开时的版本、最新版本和草稿。撤回后的历史仍可查看。编辑、撤回与新增都在悬浮窗中打开：底层列表和详情保持原样，窗口关闭前若有未提交内容会先确认丢弃。

新增正式记忆可直接保存，也可选择「整理后保存」。后者由 DSH 任务 Agent 参考同范围资料，提炼内容并选择准则、档案或正式记忆。发现重复或疑似冲突时保留表单。普通对话模型调用 `mnemoweave_remember` 只提交候选。运行时记忆与项目档案的新增、编辑使用同一悬浮窗，不再替换页面已有的列表与详情。

技能回测对当前版和草案使用同一模型配置、场景及检查项。任务 Agent 在工具受限的会话中模拟步骤和回答，独立评审逐项判定。回测报告显示两侧结果及退步项。回测失败时仍保留当前页面的草案和用例。技能页与其它页面使用同一套卡片和控件：左栏为会话复盘，右栏为文本回测与结果。

同步是本机 Server 的一项设置，作为设置卡片内的一个分组显示，与「本机连接」相邻；范围表、本次同步结果和「立即同步」都在该分组内，不单独占一张卡片。草案采纳、持久化和恢复状态见 [当前状态](status.md)。

## 会话接入

每次 `system-prompt/assemble` 重新取得 View，按准则、工作上下文和正式记忆渲染。DSH 提供正式记忆召回、按修订读取、准则读取、项目档案检索和候选提交工具。档案检索先返回匹配条目的元数据，按 ID 获取全文。

## 配置与运行

插件构建和导入见 [插件说明](../plugins/README.md)。偏好、Cordis 配置和环境变量由共享配置模块统一解析。界面偏好保存在 DSH profile，服务令牌来自受保护的 profile 配置或环境。连接限制在 loopback。设置页可测试连接、唤醒 Server 或发起计划任务注册。宿主只在本机拒绝连接且允许自动启动时尝试唤醒。

桌面操作与验证判据见 [宿主验收](host-acceptance.md)。
