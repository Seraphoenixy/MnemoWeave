# Bridge、副本与离线：已确认基线及待选择边界

## 不再重开的架构决定

- 常驻 Shared Bridge，多 Host 共用；Windows 用户级后台运行，Linux systemd --user。
- 本地 SQLite、持久化队列、远端记忆逻辑副本和有限运行缓存。
- Recall Local-first，必要时远端补充；不要求所有操作实时访问 Server。
- 周期同步结合条件触发；快照初始化、增量批处理、定期全量校验。
- 本地数据应用与 Cursor 同一 SQLite 事务提交。
- 支持 Tombstone、撤权、游标失效、索引修复和副本重建。
- Bridge 身份、Host 身份和作用域授权分离，能力声明不代表授权。

## 与全文权威的关系

Q2 方案 A 确定的是正式版本的权威。Bridge 的本地正文是远端授权发布结果的派生只读副本，不成为可独立批准或改写正式知识的第二权威。用户已确认 SYNC-01：同步授权范围内的当前与历史全文，因此历史 Recall 也可离线完成；不得自行缩减成仅当前正文或查询缓存。

离线队列保存的是待 Server 处理的操作意图，不是离线完成的正式写入。恢复连接后必须重新检查授权、目标基线、幂等键和审核要求；撤权、过期或基线冲突不能用本地旧判断自动放行。

## 第三批已确认

| 决策 | 待选择内容 | 影响 |
|---|---|---|
| SYNC-01 | 当前及历史版本全文均复制，限当前授权允许范围 | 历史 Recall 也支持离线；磁盘和同步量较大 |
| SYNC-02 | 候选、事件、版本和关系变更意图均可持久化排队 | 重连后 Server 重验权限、基线、幂等和审核，冲突显式处理 |
| AUTH-01 | 离线读取许可默认 1 小时，由 Server 配置 | 许可到期未续期停止读取；连接获知撤权时立即停止 |

Lease 是离线读取许可，不等同于长期身份凭据有效期、Session 生命周期或同步间隔。收到撤权时立即停止相关访问；断网无法获知的新撤权只能在再连接或许可到期时执行，不能承诺瞬时远端撤销。

许可不得被 Bridge 自行续期，重启或反复打开 Host 不能重置有效期。无法可靠判断剩余有效期时，停止离线读取并要求重新授权；时钟与重启的具体校验机制后续细化。

## 派生的实现要求

- 正式副本覆盖授权的版本正文、版本身份/状态、当前指针及关联检索所需元数据；默认有效 Recall 与显式历史 Recall 区分，历史存在不代表当前有效。
- 未授权历史、全部 Session 原文、服务端模型凭据不因“全历史副本”而被复制。候选队列属于本地待提交数据，不混为已发布正式副本。
- 离线意图必须保存稳定身份、原始内容及提交时的目标版本基线。重连不能偷偷改成最新基线、自动覆盖新版本或绕过审核。
- 本地入队确认只表示已持久化排队；Server 接收也不等于正式写入完成。只有对应审核及持久化回执满足要求后才能显示为正式成功。
- 本地意图不能因为副本重建、Cursor 更新或索引修复而丢失。队列与副本数据的切换必须有明确隔离边界。
- 同步失败、历史未同步齐、许可过期或权限被撤销必须区分，不能以空 Recall 或“已同步”掩盖异常。

## 第四批已确认

- **变更入口**：MnemoWeave 使用专用 Mnemon Store。正常正式变更统一由 MnemoWeave 审核、执行和发布；三个 Host 经 Bridge/MCP 接入。外部记忆经导入与审核，不将旁路写入当作正常受支持流程。
- **同步默认值**：30 秒增量同步、3 天（72 小时）全量校验。用户明确指定 3 天，不采用此前推荐的 24 小时。重连与关键业务事件额外触发；默认值可由配置管理。
- **重建期间**：在暂存区域构建新一代副本，完整校验后一次切换；旧副本仅在结构完整且读取许可有效时继续服务，并显示数据时间与过期状态。联网时可向 Server 补充查询。
- 旧副本损坏、无法证明结构完整或读取许可已过期时，禁止本地读取。重建不能重置许可、扩大授权或丢弃离线队列。

全量校验不等于每 3 天重新下载全部正文：实现方应验证逻辑记录、版本指针、关系、删除/撤权状态和内容哈希，按差异修复；无法证明一致时重建。校验的具体分区/摘要协议在同步契约中细化。

专用 Store 是部署与接入约束，不是假定 Mnemon 能识别所有调用方或提供全局写锁。检测到未经编排的外部改变时应进入完整性异常处理，不把缺少审核/发布事件的变化静默并入正式变更流。
