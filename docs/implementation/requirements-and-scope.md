# 需求与范围

状态：首版范围 Accepted（DOC-01，2026-11-08 用户确认）；实现状态为本轮核查结论，只表示代码事实，不构成新的范围决策。

依据：`../adr/README.md`、`../sources/p0-r20-user-summary-2026-11-08.md`、`decision-register.md`。本文回答“首版交付什么、非目标是什么、按什么顺序完成”，不重开已确认的架构选择。

## 1. 产品边界

MnemoWeave 是独立的 AI Agent 记忆编排系统：

- 正式记忆正文、原生实体关系与检索由 Mnemon 提供；MnemoWeave 通过已核实的官方 CLI 使用它。
- MnemoWeave 负责候选审核、可靠写入、逻辑版本与冲突治理、多 Host 接入、Bridge 本地副本与同步、治理数据生命周期。
- 主语言 TypeScript strict，Workspace Monorepo，模块化单体，原生部署，不以 Docker 为前提。
- 当前目标 Host 为 DSH、ChatGPT 桌面、ZCode；Codex CLI 仅保留历史代码与证据。

首版范围（DOC-01 已确认）：Server、Bridge、本地副本、同步、DSH/ChatGPT 桌面/ZCode 接入；后续扩展单列。

## 2. 非目标

以下不属于首版，且不得以附带实现扩张范围：

- 通用文件同步、云盘备份或 Git 仓库作为记忆权威（ADR-020）。Bridge 副本是授权记忆的派生数据，不是通用备份。
- Docker 化部署、独立队列服务或独立 Worker 进程（ADR-018/026）。
- 读取或修改 Mnemon 内部 SQLite 表作为产品接口；伪造官方 HTTP/MCP 接口。
- 复刻 DSH 插件运行时、Cordis Fiber、客户端页面或私有 RPC；DSH 只作为 Host 接入目标。
- 由 Provider 自行寻找模型、静默降级模型或让模型直接写正式记忆。
- 首版不承诺通用远端 HTTP 对外服务、TLS 终结、多租户计费或模型质量评测平台。

## 3. 角色

| 角色 | 职责 | 明确不具备 |
|---|---|---|
| 用户 | 确认范围与关键决策、首次配对 Host、人工例外裁定、配置运行环境 | 不通过 MCP 工具代替用户身份 |
| Operator | 通过独立令牌执行 approve/reject/amend、冲突裁定、失败重试、版本取消 | 不是模型角色，令牌不进入 Host/MCP 环境 |
| Host Agent | 提交候选、Recall、查询回执；接收自动注入的上下文 | 不能批准候选、不能直接 Remember、不能扩大 Grants |
| Bridge | 共享用户级进程，持有本地副本与离线队列，向 Host 提供本地优先读取 | 不是第二写入权威，不自行批准或发布 |
| Server | HTTP/MCP 协议层 + Application Core + 进程内 Worker，协调 Mnemon 与治理库 | 不能绕过审核或业务占用 |
| Mnemon | 正式记忆内容、原生关系、检索与去重语义 | 不提供 MnemoWeave 的业务当前指针或审核状态 |

## 4. 用户流程

1. 提交与审核：Host 提交候选 → 确定性规则 + 语义检查 → 自动批准/拒绝或转人工 → 同事务登记 Task/Outbox → Worker 写入 Mnemon → 官方读取核对 → 回执与发布。
2. 读取：在线经 Server、离线经 Bridge 本地副本；默认有效读取排除未发布与被替代内容，显式历史读取返回版本与状态。
3. 版本与冲突：带 `change` 意图的候选必须人工确认；稳定基线 CAS + 持久化业务占用；冲突案件保留双方证据，未裁定不发布新结论。
4. 离线：读取许可有效时使用本地副本；许可过期后仍可接收新内容意图；收到撤权立即停止读取。
5. 升级与恢复：治理库版本化迁移，迁移前一致快照；恢复只针对治理数据，Provider 内容另行核对。

## 6. 首版完成门槛

- DSH、ChatGPT 桌面、ZCode 均需通过自动注入与必需事件采集验收。当前有 ZCode hook 实进程链路验证；三个目标 Host 的完整真实会话验收尚未完成，首版不能标记交付。Codex CLI 历史验收不计入门槛。
- 关键 Pinned 超出预算时返回明确异常，不静默截断（VIEW-01/02）。
- 版本发布满足 CAS、业务占用、前向恢复与冲突裁定的验收场景（见 `state-machines-and-transactions.md`）。
- Bridge 同步满足授权范围、离线许可、Cursor 失效与暂存重建验收。
- 迁移、恢复与回退步骤经过演练，且不覆盖用户现有目录。

## 7. 已确认策略的实现状态

这些不是范围变更；下列为已确认策略的当前实现状态与剩余缺口：

- HOST-05 的注入控制器与 2 秒上限已实现；Bridge 按会话持有控制器并暴露 `/v1/inject`，View 优先用本地副本组装、回退服务端装配；ZCode 钩子优先连接 Bridge。
- 2 秒上限、4,096 Token 兜底预算、保留清扫逻辑、模型用量记录、Rerank 已有实现与契约测试；Server 软 10 GiB / 硬 20 GiB 配额已实现，Bridge 不设配额。
- 模型预算 60 秒/5 分钟/3+1 次与后台并发 2 已在网关与审核循环实现；写入仍由单一全局锁串行化，TASK-02 交互优先（写入先于长模型调用）已实现。

- 新增或缩减范围必须写入 `decision-register.md`，只有用户明确选择才能标记 Accepted。

- 文档、实现与 ADR 冲突时，先记录冲突并停止扩张，不以实现反推决策。

运行时记忆的当前实现与行为验收见 runtime-memory.md；不能由 M0–M5 的基础设施完成度推断产品主链路已完成。
