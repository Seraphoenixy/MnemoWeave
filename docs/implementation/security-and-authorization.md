# 安全与权限

状态：目标政策 Accepted（AUTH-01 至 AUTH-05、STORAGE-01、OPS-01）；当前实现为本地开发保护，不代表目标身份体系。细化见 `identity-and-offline-access.md`、`../architecture/security-architecture.md`。

## 1. 三个独立判断

| 判断 | 通过意味着 | 不能推出 |
|---|---|---|
| Host 身份验证 | 请求来自已登记 Host | 不能读全部项目、不能使用过期许可、不能审核 |
| 读取许可有效 | 在授权范围与时间内可读本地正式副本 | 不能批准写入、不能更新版本基线 |
| 接收本地意图 | 可持久化用户新提供的内容 | 不代表 Server 已授权、审核或写入成功 |

不得用单个 `authenticated` 布尔值替代。组件能力声明不构成授权；Grants 在实际操作边界检查。

## 2. 当前实现（开发边界）

- 仅监听 `127.0.0.1`；HTTP 使用 Bearer 令牌，长度至少 24。
- operator 令牌独立，不得与普通令牌相同；只在 HTTP 边界校验；stdio MCP 继承启动者权限，不暴露审核工具。
- 带 `Origin` 头的请求拒绝；不做 CORS；不提供 TLS。
- 操作人固定记为 `local-operator`，不读取模型输入中的操作人字段。
- 该保护不能作为远端部署或生产身份系统；不得对公网开放。

## 3. 目标身份与授权

- Bridge 身份、Host 身份、作用域授权三者分离，可分别撤销与轮换。
- 首次配对由用户确认，签发每 Host 独立凭据；后续会话自动连接，不重复人工配对。
- 授权记录必须能表达“当前及未来全部项目”的通配范围；Global 单独授权。
- 每次读取与写入都重新应用调用者 Grants；一个 Host 失权不得误伤同一 Bridge 上其它仍授权 Host。
- 撤权只影响读取与后续操作；已交付给模型的上下文不能强制收回，文档与实现都不得承诺“遗忘”。

## 4. 离线许可

- 默认 1 小时，由 Server 配置与续发；Bridge 不得续期，重启或重开 Host 不重置。
- 许可到期：禁止读取本地副本；身份有效且未明确撤权时仍可接收新意图。
- 明确撤权：立即停止受影响读取与接收；未上传意图隔离保留，不自动提交。
- 无法可靠判断剩余有效期时停止读取并要求重新授权。

## 5. 凭据与存储

- 本地 SQLite 不额外加密（STORAGE-01）；依赖操作系统用户级权限，磁盘加密由用户自管。
- 模型、Bridge、Host 凭据不得写入普通诊断日志、回执、提示词或 Git。
- 凭据解析在调用边界完成；轮换后旧凭据失效，不能靠重启恢复。
- 不得宣称可以抵抗已控制同一用户会话或系统管理员的进程。

## 6. 数据暴露边界

- 错误响应只返回错误码与 traceId，不回传 stderr、路径、正文或凭据。
- 诊断日志默认 30 天，不记录记忆正文、完整提示词、密钥或大型原始输出。
- 审核记录、正式回执、版本关系与必要证据不随诊断日志轮转消失。
- Provider 目录与管理响应对凭据脱敏；只返回已配置字段名，不返回值。

## 7. 威胁与不做的防护

覆盖：未授权本地访问、令牌混用、跨 Host 越权、过期许可继续读取、撤权后上传、日志泄漏、损坏副本注入。

不覆盖：已取得用户会话的攻击者、恶意系统管理员、物理访问、供应商侧数据驻留、TLS 终结与证书管理、DDoS 与速率限制。

## 8. 未决事项

- 配对请求的单次凭证、确认通道与过期时间。
- 凭据算法、存储位置、轮换周期与多设备撤销。
- 许可时钟与重启校验（防本地改时钟）。
- Bridge 与 Server 的传输认证与最小 TLS 配置。
- 审计日志的保留期与导出格式。
