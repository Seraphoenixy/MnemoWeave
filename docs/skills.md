# 技能管理

**技能管理**（`dsh-mnemo-weave-source-skills`，当前标记为**实验性**）用于管理工作区可加载的 DSH 技能：启停、调用、编辑、版本对比与恢复、对话自进化、用例回测与市场安装。技能管理默认开启，自进化默认关闭。

技能本身以带有 `SKILL.md` 的文件夹形式保存在 DSH 的技能目录中，遵循 [Agent Skills](https://agentskills.io/specification) 格式。技能管理页面本身不调用模型；技能仅通过 DSH 自带的 `skill` 工具进入模型上下文，不向回合的记忆 View 注入内容。

## 入口与设置位置

| 位置 | 功能 | 打开方式 |
|---|---|---|
| [技能管理页面](#skills-技能管理页面) | 管理技能、处理进化建议与草案、评测用例、安装市场技能 | **记忆系统 → 技能管理**，或开启独立侧边栏后的**技能管理** |
| [对话中](#skills-对话中) | 显示当前回合使用的技能及复盘建议 | 回合结束后下方的**本回合技能**行 |
| [设置](#skills-设置) | 开关自进化、草案预算、复盘参数、对话提示与侧边栏入口 | **记忆系统 → 设置 → 技能管理**，或技能管理页面齿轮 |

## 链接技能的写入权限

通过符号链接或 junction 引入的技能根目录、技能包目录及 `SKILL.md` 默认只读。在**设置 → 技能管理**中开启**允许更新链接技能**（`skills.allowLinkedUpdates`，默认 `false`）后，编辑、调用开关、版本恢复与草案采纳会更新解析后的原始文件并保留链接，影响共享同一目标的所有 Agent；内容哈希与修订检查仍拒绝过期写入。关闭后禁止后续链接更新与采纳，已产生的修改与版本历史保留。链接根目录中新建/安装技能与回收站规则不变。

<a id="skills-技能管理页面"></a>

## 技能管理页面

页面包含五个标签：**技能**、**进化**、**评测**、**市场**与**回收站**。**进化**标签上的数字徽标表示当前待处理的建议与草案总数。

<a id="skills-技能"></a>

### 技能

宽屏下技能列表与选中技能的文档各自独立滚动，切换技能时详情从顶部显示且列表保持滚动位置；窄屏下列表置于文档上方。

![技能：按所在位置分组的技能，其中一个被覆盖；release-notes 有一条改进待处理](https://raw.githubusercontent.com/omdsh-dev/dsh-mnemon/main/docs/assets/skills-v0.5.34/zh-CN/skills-library.jpg)

列表按 DSH 发现优先级分组展示可加载的 `SKILL.md`：项目的 `.dsh/skills`、`.agents/skills`，随后是用户的 `~/.dsh/skills`、`~/.agents/skills`。同名技能仅加载最靠前的一份，其余标记为**被覆盖**；DSH 拒绝加载的文件在列表下方计数并可展开查看原因。

- **开关与使用**：每行提供开关（同时控制模型自动加载与 `/` 菜单可见性）；悬停出现**使用**按钮，点击回到对话并在输入框填入 `/技能名`。行上的圆点表示实际加载的技能存在待处理改进建议。
- **新建**：按名称与描述在所选位置创建 `SKILL.md`；名称仅允许小写字母、数字和单个连字符。
- **详情操作**：支持**使用**、**编辑**、**生成改进草案**（由任务 Agent 起草，可附加要求）与**移除**（将技能文件夹移入**回收站**）。
- **调用方式**：可选**自动与 / 命令**、**仅 / 命令**、**仅自动加载**或**关闭**，对应写入 `disable-model-invocation` 与 `user-invocable` frontmatter 字段。
- **测试、版本与文件**：**测试**行显示用例数与上次得分，点击跳转到**评测**页对应技能；每次写入均按文件 SHA-256 校验，防止覆盖外部并发修改，并在**版本**中保留历史副本供对比与恢复。

<a id="skills-回收站"></a>

### 回收站

**回收站**列出被移除或替换的技能名称、移除时间、原路径、目录/单文件布局与占用大小。

- **恢复**：将已知来源的条目放回原路径（项目技能恢复到记录所属的原项目，即使当前切换了工作区）；缺少来源记录的旧条目需先选择恢复位置。
- **同名冲突**：已存在同名技能时可选择改名恢复、确认替换（校验当前文件哈希，并将被替换技能保留在回收站）或取消。
- **彻底删除 / 清空回收站**：需输入技能名称或二次确认，永久删除磁盘文件。

<a id="skills-进化"></a>

### 进化

**进化**页追踪进行中的草案与评测任务，在任务完成后自动刷新卡片；切回窗口或浏览器标签页时重新读取状态。

- **模型选择**：**全局模型**设置生成与重写草案的默认模型；**所选草案模型**仅覆盖当前建议；未设置时跟随任务 Agent 默认模型；选择保存在 `skills/preferences.json`。
- **待处理 / 已处理 / 证据**：**待处理**列出建议与直接生成的草案；**已处理**保留已采纳、已忽略、已过期或已失效记录；**证据**列出复盘读取的对话轨迹；星形按钮**复盘本会话**可立即触发当前对话复盘。
- **删除建议**：同步清理复盘记录与证据中的关联条目，已记录的对话轨迹与评测用例保留。

| 建议及其证据 | 回测过的草案 |
|---|---|
| ![进化 · 待处理：改进 release-notes 的建议，展开了所依据的证据](https://raw.githubusercontent.com/omdsh-dev/dsh-mnemon/main/docs/assets/skills-v0.5.34/zh-CN/skills-suggestion.jpg) | ![建议下的草案：说明与改动、回测“当前 40 → 草案 93 +53”，以及差异](https://raw.githubusercontent.com/omdsh-dev/dsh-mnemon/main/docs/assets/skills-v0.5.34/zh-CN/skills-draft.jpg) |

- **建议**：说明目标（新建或改进）、理由、来源对话与置信度；支持**生成草案**、**忽略**与展开查看引用的对话步骤。
- **草案**：展示改动说明、回测得分对比及差异视图；支持**采纳**、**放弃**、**编辑草案**与**按要求重写**；回测得分低于当前版本的草案在采纳前需二次确认。
- **证据**：按编号步骤展示记录的对话（用户消息、工具调用及结果、技能加载）与复盘标注；支持**置顶**以防止清理，以及勾选步骤生成测试用例。

![进化 · 证据：四段记录的对话；版本说明这段对话的信号与编号步骤](https://raw.githubusercontent.com/omdsh-dev/dsh-mnemon/main/docs/assets/skills-v0.5.34/zh-CN/skills-evidence.jpg)

改进建议绑定原技能文件路径及所属项目，切换存储范围不改变目标。原文件被删除或移动时，提示错误且不采纳到其他同名技能。

<a id="skills-可选的自动采纳"></a>

#### 可选的自动采纳

**自动采纳新建议**（`skills.autoAdopt`）默认关闭。同时开启自进化、草案自动回测与该开关后，仅处理空闲审查**新建**的建议（继续遵守 `skills.allowCreate` 与 `skills.allowUpdate`），不批量处理历史建议、手动复盘建议或仅追加证据的已有建议。

执行流程：

1. 按建议或全局草案模型起草 `SKILL.md`。
2. 使用相同的回测模型、推理强度与全部启用用例集运行基线与候选回测。若启用用例数超过 `skills.casesPerRun`，或出现错误、中断、图片依赖用例、用例/草案并发变动，则停止自动采纳并保留人工审查。
3. 要求候选在每个用例上均不退步且不丢失原通过的检查项；出现退步时带逐项结果最多**重写两次**（共三次草案尝试）；仍退步则留在人工审查列表。
4. 最终在 Source 写锁内重新核对草案、用例、回测结果与当前技能 SHA-256 后写入并记录版本。

内存队列上限为 16 个建议，串行处理；服务重启不续跑未完成队列。

<a id="skills-每日候选预算与复用价值参考"></a>

#### 每日候选预算与复用价值参考

- **每日自动处理候选数**（`skills.autoAdoptDailyLimit`，默认 `2`，范围 `0..100`）：按 Skills 存储目录统计，在 Source 写锁内、模型调用前预留名额；同一技能文件每天最多进入一次，尝试、取消与失败均计入，重写共用同一名额；设为 `0` 时暂停自动处理。
- **每日额度时区**（`skills.autoAdoptTimeZone`，默认 `local`）：支持 `local` 或 IANA 时区名（如 `Asia/Shanghai`）。账本保存在 `skills/auto-adoption-budget.json`（保留 72 小时，跨重启保留）。
- **确定性证据分类**：引用至少 3 段不同证据、20 个不同引用步骤且置信度 `>= 0.8` 标记为**可复用流程**；仅 1 段且不足 20 步标记为**一次性候选**；其余标记为**需要判断**。分类仅影响列表分组与折叠展示，不改变自动采纳条件。

### 评测

![评测：每个技能的用例数与最近得分；release-notes 的三个用例与逐个用例的回测结果](https://raw.githubusercontent.com/omdsh-dev/dsh-mnemon/main/docs/assets/skills-v0.5.34/zh-CN/skills-evals.jpg)

列表按有用例的技能、无用例的技能、建议中尚未创建的技能（**未创建**）排序。手动回测（含草案与基线对比）依次采用技能覆盖模型、评测页全局模型、任务 Agent 默认模型。

- **用例结构**：包含标题、任务描述、可选背景与检查项（**必须**或**建议**）。
- **模拟运行与计分**：执行者按技能输出行动步骤但不调用真实工具，裁判逐项判定并提供原文引用（缺少有效引用的评分不能用于自动采纳）。所有**必须**项通过才算通过该用例，计分时**必须**项权重为 2 倍。
- **依赖图片输入**：勾选该标记的用例在纯文本回测中显示**未测**，不调用模型，不计入得分与基线对比。

### 市场

![市场：搜索 changelog，已添加的来源中找到 1 个，skills.sh 找到 30 个](https://raw.githubusercontent.com/omdsh-dev/dsh-mnemon/main/docs/assets/skills-v0.5.34/zh-CN/skills-market.jpg)

| 来源类型 | 说明 |
|---|---|
| **精选**（内置） | 内置技能索引，从上游仓库安装 |
| **skills.sh**（内置） | 输入 2 个字符以上搜索开放索引，按安装量排序 |

- **添加来源**：支持 `owner/repo`、GitHub / skills.sh 链接、网站 URL、JSON 路径或 URL；粘贴到搜索框时也会显示直接添加操作。
- **安全与安装**：安装前可预览 `SKILL.md`、文件列表、许可证与 skills.sh 安全审核结果；下载内容限制文件数与体积，禁止路径逃逸技能目录，网站压缩包校验 SHA-256 摘要；技能可能包含脚本，dsh-mnemo-weave 本身不执行技能脚本。

<a id="skills-自进化"></a>

## 自进化工作流

1. **轨迹记录**：每回合结束时由 Host 记录用户消息、工具调用及结果、加载的技能（机密信息先脱敏替换）。
2. **触发条件**：同一工作区至少两段独立会话（改进已有技能需两次使用同一技能并在同一工具失败后恢复；新建技能需两次未加载技能时以相同工具顺序和输入成功执行），且对话窗口积分达到 `skills.reviewThreshold`（默认 `5`）并在连续空闲 `skills.idleSeconds`（默认 `20` 秒）及冷却 `skills.cooldownSeconds`（默认 `150` 秒）后，启动任务 Agent 评估。
3. **建议准入与去重**：置信度低于 `skills.minConfidence`（默认 `0.6`）的建议不入账；同技能文件同类建议仅保留 1 条未完成记录；被忽略的建议 24 小时内不在同一对话重复提出；单对话待处理上限为 `skills.maxPendingPerSession`（默认 `5`）；超过 `skills.expiryDays`（默认 `7` 天）未处理则过期。
4. **连续失败熔断**：复盘失败记录在对应回合下并保留积分窗口；同一对话连续失败 3 次后停止自动复盘，直到 DSH 重新创建该会话 Agent。

<a id="skills-设置"></a>

## 设置与数据存储

全部 `skills.*` 配置键、默认值与取值范围见[技能管理设置](configuration.md#技能管理设置)。

技能进化数据保存在当前存储根目录的 `skills/` 下（不属于 Mnemon Pack 备份与服务器同步范围），完整目录结构见[技能管理存储模型](architecture.md#storage-技能管理)。

<a id="skills-数据与信任"></a>

## 数据与信任

- **技能文件位置**：编辑、安装和采纳直接写入 DSH 读取的技能目录；删除或替换的技能先移入**回收站**。
- **技能管理数据**：建议、草案、安装记录、测试用例、回测结果、记录对话、版本历史与市场缓存保存在当前存储根目录的 `skills/` 下（见[技能管理存储模型](architecture.md#storage-技能管理)），不属于 ZIP 备份与服务器同步范围。
- **记录的对话**：仅保存复盘所需字段（用户消息、工具调用及结果、技能加载），机密先脱敏替换；最多保留最近 100 段，置顶或被引用的条目最后清理。
- **任务及子代理会话**：由 DSH 保存在其会话目录（默认 `~/.dsh/sessions/`），释放实例或删除证据记录不会自动清理；关闭**自进化**仅停止后续自动复盘。
- **模型调用边界**：仅自进化复盘、生成草案、回测与从证据生成用例调用模型；浏览、编辑、开关与安装不调用模型。
- **市场访问限制**：GitHub 对未认证请求每小时限 60 次，列出仓库的请求在 10 分钟内缓存复用；在 DSH 运行环境中设置 `GITHUB_TOKEN` 或 `GH_TOKEN` 可提高限额。

<a id="skills-常见问题"></a>

## 常见问题与任务恢复

| 现象 | 处理 |
|---|---|
| **进化**一直是空的 | 确认已开启**自进化**及至少一类建议。自动评估需要跨会话的技能问题证据；可用**复盘本会话**立即评估。 |
| 回合下显示**复盘失败** | 任务 Agent 未返回有效结果，积分窗口保留到下一次；连续失败 3 次后停止自动复盘，直到 DSH 重新创建会话 Agent。 |
| 提示 *GitHub declined to list …* | GitHub 本小时额度耗尽；等待额度恢复，或设置 `GITHUB_TOKEN` / `GH_TOKEN`。skills.sh 预览仍可展示其保存的文本副本。 |
| 提示 *skills.sh is busy* 或 *skills.sh 暂时无法搜索* | 稍后重试；已添加的其他来源不受影响，可在**来源**中关闭 skills.sh。 |
| 提示 *… publishes no Agent Skills index* | 目标站点在指定路径与根目录下均无 `/.well-known/agent-skills/index.json`。 |
| 草案显示 *回测结果无法比较* | 两侧均无成功运行的用例；查看逐用例错误后点击**重新回测**。 |

<a id="skills-恢复草案或回测"></a>

### 恢复草案或回测

- 草案生成超过 15 分钟、回测超过 45 分钟时自动中止；最多同时运行 2 组回测、每组最多并行 2 个用例，运行与等待任务总数上限 16 个；Source 启动及每分钟检查会将超时任务持久化为中断状态。
- 原技能变更或新建目标出现同名技能时，卡片提示冲突并提供**重新生成并回测**；编辑旧草案不绕过文件 SHA-256 哈希校验。
