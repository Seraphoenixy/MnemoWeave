# 当前状态

## 已实现

- 本机 HTTP 与 stdio MCP、候选审核、Worker 可靠写入、正式记忆目录、版本与冲突治理。
- 运行时准则、项目档案和正式记忆的浏览与写入。正式记忆支持撤回和历史读取。
- 远端同步服务、设备授权、版本确认、Outbox/Inbox、断网恢复和按范围快照重建。
- DSH 会话注入、模型工具、记忆编辑、用户触发的整理后保存，以及技能页中的会话复盘、草案和文本回测。
- Windows 本机 Server 发布、计划任务注册与唤醒。Linux 远端部署单元已提供。

## 验证覆盖

| 层级 | 证据 |

| 自动端到端 | 真实 Mnemon 0.2.13、发布与恢复、并发编辑、两机与三机同步、离线恢复、快照重建、DSH Host 半 |
| 实机 | Windows 计划任务注册及唤醒；DSH 基本浏览编辑和注入记录 |

测试命令见 [根目录 README](../README.md)，真实宿主判据见 [宿主验收](host-acceptance.md)。
