# 记忆界面设计

本文定义各宿主共用的记忆界面，以及 DSH、ChatGPT 桌面和 ZCode 的宿主适配。交付状态见 [当前状态](status.md)。

## 通用界面

### 信息架构

| 功能区 | 内容 |
|---|---|
| 概览 | 本机连接、条目数、当前工作区绑定及最近一次准则注入结果 |
| 准则 | 查看、新增、编辑、启停和移除。显示已用字节和总容量 |
| 工作区档案 | 选择工作区、搜索、查看来源与验证状态、新增、编辑、归档、恢复和版本历史 |
| 正式记忆 | 检索、筛选、分页、正文、修订历史、关系图谱与实体索引，以及新增、编辑和撤回 |
| 设置 | 本机连接、同步、备份与恢复、注入与召回诊断 |

功能区可映射到宿主的页签、侧栏或独立页面。对宿主缺少承载入口的功能，使用宿主可用的用户入口，并说明其能力边界。功能区名称、动作含义和结果状态在不同宿主中保持一致。

### 授权、编辑与结果

- 用户界面通过宿主侧代码访问本机 Server。服务令牌和同步凭据不进入渲染端或模型上下文。界面只提供用户有权执行的动作，实际读写仍由 Server 校验。
- 编辑和状态变更携带表单打开时读取的版本。遇到版本冲突时保留草稿，展示读取时版本、最新版本和草稿，供用户比较后重提。关闭有未提交内容的表单前确认是否放弃。界面保留用户正在查看的列表和详情位置。
- 正式写入分别展示待审、排队、结果未知、重复、失败和已发布。排队和结果未知时保留草稿和任务回执，可查询原任务。重复时可打开已有条目。写入成功后刷新受影响的列表和详情。
- 「整理后保存」先由用户确认目标记忆类型。选择工作区档案时明确目标工作区。整理任务和直接编辑各走对应的授权写入契约。

### 准则

显示当前有效准则及其启用状态。容量按 UTF-8 字节展示，默认 10,000 字节。超限时保留表单并提示删减。所有可见且启用的准则全文常驻。宿主无法完整交付时在注入诊断中记录失败。

### 工作区档案

工作区选择器只列出用户有权访问的工作区。列表、搜索、详情和容量随当前选择变化；切换时清除上一工作区的详情与结果。已绑定会话可预选对应工作区，保存前由用户确认目标。无绑定时不预选。无可访问工作区时不提供写入入口。管理页选择不改变会话绑定。

单篇正文上限 2 MiB，每个工作区活跃正文默认上限 10 MiB。归档条目不占活跃容量。历史按版本倒序显示，归档或恢复需提交读取时的版本。容量不足时保留草稿，显示可释放容量的档案供用户选择。可直接归档，或先评估可复用知识，确认提炼发布后再归档。显示提炼和归档各自的结果，归档成功后可重试原草稿。

#### 从档案提炼正式记忆

在活跃或已归档的档案详情中发起「提炼为正式记忆」。预览来源版本、完整草稿与 Mnemon 分类，并说明正式记忆的共享范围。用户可修改、放弃，或选择「确认共享并发布」。来源版本变化时提示重新提炼。排队、结果未知或待审时保留草稿与回执。DSH 重开页面后可查询原确认结果。若已确认「发布后归档」，继续使用原归档变更标识和预览版本。重复时可打开已有正式记忆。原档案继续保留。正式记忆详情只在本机且用户仍有来源档案读取权限时显示「查看来源」。[提炼与发布契约](implementation.md#从档案提炼正式记忆)

### 正式记忆

对所有工作区展示同一个共享集合。内容、图谱、详情、历史和写入表单不带工作区归属字段。用户可在检索文本中加入工作区名称作为召回线索。新增正式记忆使用 Mnemon 分类，可用多个标签记录工程主题和场景。撤回后的历史仍可查看。主会话主动提出工程经验后，按实际回执显示已发布、重复、待审或失败。候选状态与正式发布分别显示。

「整理记忆」接受用户指令，在共享集合中查找正式记忆。执行前展示逐项计划：动作、原因、证据、目标及条目版本，编辑和撤回展示原正文，新增和编辑展示拟写正文。默认不勾选任何项，用户勾选并确认后才提交。用户明确指定撤回目标时才提供撤回动作。执行中逐项显示状态和回执。完成后刷新列表，保留失败项供核对。[写入任务与发布](implementation.md#写入任务-agent-与发布)

### 设置与诊断

区分本机连接和远端同步。同步状态显示已授权同步流、本次结果和立即同步入口。准则注入诊断显示最近结果和失败原因。召回诊断显示 Provider 的向量覆盖、嵌入模型及推导出的召回模式；已有补建任务时显示任务状态。诊断读取失败时显示不可用。

备份入口展示将纳入的组件，技能由用户选择。恢复前展示清单、目标位置和冲突，用户确认后才切换运行目录。[备份与恢复演练](implementation.md#备份与恢复演练)

### 宿主可选交互

- **保存回复**：宿主能提供已完成回复的正文及稳定标识时，可在回复旁提供入口。用户确认后启动写入任务。缺少回复入口时可通过记忆界面直接新增或整理。
- **技能总结**：宿主支持技能文件与任务 Agent 时，用户可选定会话和同一工作区的授权档案作为证据。任务 Agent 生成带来源与回测用例的草案，证据不足时跳过。会话结束和记忆空闲复盘均不触发起草。自动回测、手工采纳和可选自动采纳是独立动作。

## 宿主适配

### DSH

记忆中枢有六个页签：概览、准则、工作区档案、正式记忆、技能和设置。设置可选择默认打开页。新增、编辑、撤回使用悬浮窗。同步流状态和立即同步位于设置页的同步分组。会话提供「本轮不留存」入口。生效后，本轮不进入空闲复盘，模型自行发起的准则、工作区档案和正式记忆写入均会被拒绝。用户主动点击「保存回复」时仍可单独确认。空闲复盘分别显示准则变更、档案新增和跳过原因。

插件的 `mnemo-weave` 条目负责会话注入和原生工具注册，`mnemo-weave-ui` 条目负责界面。浏览器界面通过 DSH RPC 调用 Host 侧，Host 侧使用共享客户端连接本机 Server。服务令牌来自受保护的 profile 配置或环境。连接限制在 loopback。设置可测试连接、唤醒 Server 或发起 Windows 计划任务注册。只在本机拒绝连接且允许自动启动时尝试唤醒。

`system-prompt/assemble` 追加 `mnemo-weave:rules`。同轮复用首次成功读取的准则，更新下一轮生效。会话原生工具和空闲复盘规则见 [实现与契约](implementation.md#宿主工具注册)。

#### DSH 技能页

读取工作区的 `.dsh/skills`、`.agents/skills` 和用户的 `~/.dsh/skills`、`~/.agents/skills`。同名技能按上述顺序选取，页面展示可加载技能及被遮蔽或无法加载的数量。支持新建、查看历史与逐行差异、移入回收站和恢复。同名目录存在时拒绝覆盖。

技能草案、来源、用例和回测结果保存在技能状态目录，绑定工作区及技能路径。重启后可继续查看、放弃、重跑或采纳。配对回测用同一模型配置、场景和检查项比较当前版与草案，展示各项结果及退步；失败保留草案和用例。采纳前校验当前文件哈希，写入时保留旧版本。自动采纳默认关闭。开启后要求基线未变、24 小时内的配对回测完整且全部通过。同一设备按本地自然日最多启动 2 次自动采纳任务，启动前持久化预留额度；实际启动后失败或取消也占额度。重复点击同一草案返回原任务，同一技能只运行一个采纳任务。草案生成满 7 天后退出自动采纳，仍可查看或由用户重新总结。额度不限制手工采纳。

### ChatGPT 桌面

会话注入采用本地 command Hook，模型工具通过 stdio MCP 暴露。两者的配置与运行状态分别展示。MCP 工具结果不能替代具备授权的管理入口。涉及跨集合共享确认、版本冲突或写入回执时，使用能呈现这些信息的用户界面。回复旁操作只有在宿主提供明确的回复标识与用户确认入口时才呈现。

### ZCode

宿主可从工作区配置加载进程 Hook 和 stdio MCP。进入不同工作区时，以本机绑定确认档案目标。会话绑定和管理页工作区选择分别显示。工具配置、准则注入和 Server 连接分别采证；用户写入与版本冲突使用同一套通用界面规则。

宿主注册、Hook 输出与权限见 [实现与契约](implementation.md#宿主工具注册)。构建和导入见 [插件说明](../plugins/README.md)。验证判据见 [宿主验收](host-acceptance.md)。
